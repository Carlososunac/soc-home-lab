# SOC Home Lab

## 📌 Project Overview

This project documents the development of my personal Security Operations Center (SOC) home lab.

The purpose of the lab is to gain practical experience with security monitoring, Windows event logging, network activity, alert triage, log analysis, and incident investigation.

Rather than focusing only on theoretical cybersecurity concepts, this repository will document hands-on exercises, investigations, configurations, scripts, and lessons learned.

## 🎯 Objectives

- Understand how security events are generated
- Learn Windows security logging
- Understand fundamental network activity
- Collect and analyze security logs
- Practice alert triage
- Investigate suspicious activity
- Document security incidents
- Learn SIEM fundamentals
- Develop practical Security Operations skills

## 🏗️ Lab Architecture

The architecture of the lab will be documented as the environment is built.

Planned components may include:

- Windows endpoint
- Security event logging
- Sysmon
- SIEM / log monitoring platform
- Network monitoring
- Python automation tools

## 🔍 Investigations

Security investigations performed in the lab will be documented in this repository.

Examples may include:

- Failed authentication attempts
- Suspicious PowerShell activity
- Account creation
- Unusual processes
- Network anomalies
- Security alerts
